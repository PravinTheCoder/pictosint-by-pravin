# Security Policy

## Scope

Security reports for PICTOSINT itself are welcome.

Please do not include private personal information, credentials, access tokens, or unrelated sensitive data in a report.

## Reporting

If you discover a vulnerability in the project, open a private security report through GitHub's Security Advisories when available.

For issues that cannot be privately reported through GitHub, contact the project maintainer through the public contact information in the repository.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before public disclosure.

Do not test the tool against systems, accounts, imagery services, or APIs unless you have authorization to do so.
