# Contributing to PICTOSINT

Contributions are welcome.

## Before submitting

- Keep changes focused.
- Do not commit credentials or API keys.
- Do not commit private investigation data.
- Do not commit generated case folders or downloaded imagery.
- Document new dependencies.
- Test changes on a clean Python environment where practical.

## Pull requests

Please describe:

1. What changed
2. Why it changed
3. How it was tested
4. Any limitations or compatibility concerns

## Code style

Prefer readable Python, small functions, explicit error handling, and useful command-line messages.
